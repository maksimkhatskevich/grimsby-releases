# Grimsby Player

Офлайн-плеер для музыки и клипов из ваших собственных файлов. Альбомы по годам, исполнители, клипы к альбомам, умные плейлисты, эквалайзер и выравнивание громкости, подробная статистика и итоги года.

## Скачать

Последняя версия — на странице **[Releases](https://github.com/maksimkhatskevich/grimsby-releases/releases/latest)**: файл `Grimsby Player Setup X.Y.Z.exe` (Windows 10/11, 64 бит).

При первом запуске установщика Windows может показать синее окно «Windows защитила ваш компьютер» — это обычное предупреждение для программ без платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

## Обновления

Установленный Grimsby сам проверяет новые версии, скачивает их в фоне и предлагает перезапуститься. Лайки, плейлисты, история и настройки при обновлении сохраняются.

## Лицензии

Grimsby использует свободные компоненты, в том числе FFmpeg (GPL v3). Полный список с текстами лицензий и ссылками на исходный код — в программе: Настройки → О программе → Открыть список лицензий.
